# Design System

## Visual direction

Academic research portfolio meets modern AI engineering portfolio.

Reference feeling:

- clean academic lab site
- modern technical documentation
- understated AI research company

## Typography

Use one strong sans-serif family.
Prioritize readable body text.

## Layout

Max content width: approximately 1100–1200px.

Use whitespace generously.

Project sections should use cards sparingly.

## Colors

Primarily neutral:
white / near-white background
dark text
one restrained accent color

## Motion

Minimal.

Only use subtle hover/focus transitions.

## Mobile

All pages must be usable on mobile.
No horizontal scrolling.
